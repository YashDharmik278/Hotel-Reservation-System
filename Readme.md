# 🏨 Hotel Reservation System

A console-based **Hotel Reservation System** developed in **Java** using **Object-Oriented Programming (OOP)** principles. The system allows users to search available hotel rooms, book and cancel reservations, simulate payments, and manage booking records efficiently.

---

## 📌 Features

* 🔍 Search available hotel rooms
* 🛏️ Room categorization:

  * Standard
  * Deluxe
  * Suite
* 📅 Book hotel rooms
* ❌ Cancel reservations
* 💳 Payment simulation
* 📋 View booking details
* 📚 Reservation history management
* 🏗️ OOP-based modular design

---

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Java Collections Framework

  * ArrayList
  * HashMap
* Exception Handling
* Scanner Class
